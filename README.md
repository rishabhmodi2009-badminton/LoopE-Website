# Loope Leashes

An website for a Company Website that creates recycable dog leashes. The company name is LoopE. Include tabs Shop, About, Why Choose Us, Buy, and Contact. The logo should be at the top left. Include place holder images for now. The starting page should be reachable through the logo on the top left. The logo is attatched. The front page should be a very simple summary of the things in every tab. Try matching the colour scheme with the logo, meaning black, white, and shades of green.
